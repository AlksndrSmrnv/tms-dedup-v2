# Prompt: infer_section_axes

## Задача

Тебе даётся **одна sibling-группа** — родительская секция TMS и набор её
прямых дочерних секций. Для каждой дочерней секции Python-пайплайн уже
собрал: имя, distinctive-токены, частые токены заголовков тестов,
количество тестов. Плюс есть авто-гипотеза с confidence.

Нужно вернуть **один JSON-объект** (без обёртки), соответствующий схеме
`schemas/section_axis.schema.json`.

## Возможные значения `axis_type`

- `BUSINESS_VARIANT` — дети различаются **бизнес-вариантом**. Примеры:
  канал (телефон/карта/реквизиты/СБП), платформа (iOS/Android/Web),
  роль (юрлицо/физлицо/оператор), тип документа. Ключевой признак:
  базовый сценарий один, а «как именно» делается — разное.
- `FEATURE_GROUP` — дети описывают **разные фичи** одного раздела. Нет
  общего базового сценария.
- `TECH_GROUP` — чисто **организационная** секция: регресс, смоук,
  санити, ручные, автотесты, e2e, integration. Не влияет на
  дубликатность.
- `UNKNOWN` — нельзя уверенно отнести.

## Формат ответа

```json
{
  "parent_section": "<из входа>",
  "axis_type": "BUSINESS_VARIANT | FEATURE_GROUP | TECH_GROUP | UNKNOWN",
  "dimension_name": "<короткое имя оси, напр. \"способ перевода\">",
  "confidence": 0.0,
  "reason": "<1–2 фразы, почему именно такой тип>",
  "section_values": [
    { "section_name": "<имя ребёнка>", "normalized_value": "<компактное значение варианта>" }
  ]
}
```

## Правила

1. **Строго JSON.** Никаких комментариев `//`, никакого текста вокруг.
2. **Кириллица — как есть**, не эскейпь.
3. `confidence` — число в диапазоне `[0.0, 1.0]`. Будь честен: если
   картина неочевидна — ставь 0.4–0.6.
4. `dimension_name` обязателен только для `BUSINESS_VARIANT`. Для
   `TECH_GROUP` напиши `"tech"`, для `FEATURE_GROUP` — `""`, для
   `UNKNOWN` — `""`.
5. `section_values` должен повторять порядок входных детей и их имена
   **один-в-один**.
6. `normalized_value` — краткое имя варианта (для BUSINESS_VARIANT):
   например, `"по телефону" → "phone"`, `"по карте" → "card"`, `"СБП"
   → "sbp"`. Для прочих axis_type можно оставить `""`.
7. Если авто-гипотеза Python кажется тебе правильной — просто подтверди
   её, но дай собственное `reason`.

## Пример

Вход (сокращённо):

```text
parent_section: "Банк/Переводы"
дети:
  - "По номеру телефона" (distinctive: ["телефон"])
  - "По карте" (distinctive: ["карта"])
  - "По реквизитам" (distinctive: ["реквизит"])
авто-гипотеза: BUSINESS_VARIANT, confidence 0.85
```

Ответ:

```json
{
  "parent_section": "Банк/Переводы",
  "axis_type": "BUSINESS_VARIANT",
  "dimension_name": "способ перевода",
  "confidence": 0.9,
  "reason": "Дети обозначают разные каналы одного и того же сценария перевода",
  "section_values": [
    { "section_name": "По номеру телефона", "normalized_value": "phone" },
    { "section_name": "По карте", "normalized_value": "card" },
    { "section_name": "По реквизитам", "normalized_value": "requisites" }
  ]
}
```

## Что делать, если ты не уверен

Ставь `axis_type = "UNKNOWN"` с низким `confidence` и опиши сомнения в
`reason`. Не пытайся угадывать. Python-пайплайн перепроверит это при
финальном мердже.
